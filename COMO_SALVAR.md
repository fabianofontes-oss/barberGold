# 📖 Guia Rápido: Como Salvar e Commitar

## 🚀 Jeito SUPER RÁPIDO (recomendado!)

### 1️⃣ Commit com mensagem personalizada:
```powershell
.\commit-rapido.ps1 "o que você fez"
```

**Exemplos:**
```powershell
.\commit-rapido.ps1 "adicionei tela de clientes"
.\commit-rapido.ps1 "corrigi bug no login"
.\commit-rapido.ps1 "melhorias no dashboard"
```

### 2️⃣ Commit rápido (usa mensagem padrão):
```powershell
.\commit-rapido.ps1
```

---

## 💾 Salvamento Automático de Arquivos

### Ativar no Cursor:

1. Pressione `Ctrl + ,` (vírgula)
2. Digite "auto save" na busca
3. Mude para: **`afterDelay`**
4. Pronto! Agora salva sozinho a cada 1 segundo! ✅

---

## 📝 Atalhos Úteis

| Ação | Atalho |
|------|--------|
| Salvar arquivo atual | `Ctrl + S` |
| Salvar tudo | `Ctrl + K` depois `S` |
| Terminal | `Ctrl + '` (apóstrofo) |
| Buscar arquivo | `Ctrl + P` |

---

## 🎯 Fluxo de Trabalho Recomendado

1. **Edite seus arquivos** (salvam automaticamente se configurado)
2. **Quando terminar uma tarefa**, rode: `.\commit-rapido.ps1 "descrição"`
3. **Pronto!** 🎉

---

## ❓ Precisa de Ajuda?

- Não sabe o que escrever na mensagem? Use algo simples:
  - "correções"
  - "melhorias"
  - "atualizações"
  - "trabalho do dia"

- Esqueceu de salvar? Pressione `Ctrl + K` e depois `S`

- Quer ver o que mudou? `git status`

---

**Dica:** Sempre que você parar de trabalhar por hoje, rode o script para salvar seu progresso! 💪
